# Relationships and invitations, when wanted

Use existing interests and relationships as context for conversation, not as a
source of contacts to harvest. This project does not need a growing client base
to be valuable as a personal accessibility and creative tool.

## A small, useful introduction

Explain what the experience involves and share a relevant guide when someone
asks. Ask whether they would like further information before following up.
Let people pass. There is no evidence in this repository for a universal
conversion rate, local demand estimate, or “highest-yield” channel.

For a possible collaborator, discuss the audience, practical fit, access needs,
responsibilities, and permission to share information. Do not imply an affiliation
or arrangement before it exists. Referral compensation, if ever desired, is an
owner decision requiring clear terms rather than an assumed practice.

## Keep conversation permissions distinct

An inquiry address may be used to answer that inquiry. It is not permission for
availability notices or recurring updates. A past guest is not automatically a
subscriber. Ask separately before sharing a quotation, identifying an event,
using a photograph, or passing someone’s details to another operator.

## Minimize administration

When an approved Cloudflare inbox is configured, use `npm run inbox -- i` to
list open inquiries and `npm run inbox -- r 1` to read the first current result.
Reply privately in the agreed channel, then use `npm run inbox -- c 1` to record
the reply. Refresh the list before closing a conversation with `x` and its
current number. Keep outreach or follow-up as a reviewed draft until the owner
decides to send it. [Inbox commands](site-operations.md) · [Reply drafts](../brand/marketing/CONSULTATION.md)

Useful records are the next agreed action, the person’s stated preference, and
whether follow-up is welcome. Avoid speculative profiles, diagnoses, or
unnecessary copies of access notes. Stop a trial that costs more effort than it
returns in useful relationships.
