# Lantern Bay: a complete worked example

This pack follows a synthetic inquiry through preparation, play, and follow-up.
It is original example content created for this repository, not a real booking,
client record, provider transaction, or playtest result. Redistribution licensing
is pending under [REUSE.md](../../REUSE.md).

**Adventure:** The Last Light of Lantern Bay. System-neutral, warm mystery and
shared discovery. The example plans for four players and approximately 90 minutes;
these are scenario assumptions, not Storyscape service limits or promises.

## From zero to a session

1. Read [the inquiry](01-inquiry.md) and [scope](02-scope.md). Notice what is known,
   what needs a conversation, and what has not been agreed.
2. Read [the prep sheet](03-prep.md). Its minimum path works with just this pack,
   paper if wanted, and the group’s chosen way to communicate.
3. Share or print [the player introduction](04-player-introduction.html). It uses
   plain language, large type, visible choices, and no required character stats.
4. Run [the adventure](05-adventure.md). Every critical clue has more than one
   route; failure changes the situation instead of ending the investigation.
5. Use [the follow-up draft](06-follow-up.md) only after adapting it to what
   actually happened. Nothing in this pack sends messages.
6. Record [playtest observations](07-playtest.md). Blank observations are not
   passing results.

To make an editable private working copy without repeated copy/paste:

```sh
npm run session
```

The command creates a new, ignored `.local/sessions/` folder, copies this pack,
and writes a source checksum manifest. It will not overwrite an existing folder.
The manifest records the starting files, not session completion or approval. Keep
any real participant information out of the public repository and exports.

## Accessibility and adaptation

The facilitator can read descriptions aloud, accept spoken or written choices,
use A/B/C shortcuts, omit visual handouts, and pause without requiring an
explanation. No camera, miniature handling, timed dexterity, or memorized rules
are required by this example. Confirm the actual group’s preferences; these
options do not establish accessibility for every person or platform.

The story includes darkness, a mild storm, an old promise, and disagreement over
protecting a public place. It contains no required combat, graphic injury, or
harm to children. Replace any unwanted element before play. A player can ask for
“pause,” “skip,” or “change” at any point.
