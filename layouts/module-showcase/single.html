How to make these choices permanent

Edit the sections list in content/_index.md or a page using the modular layout. Reorder entries, remove them, or add enabled: false. Each entry needs a unique ID. Alternate versions use the variant key.

sections:
  - module: hero
    id: hero
    variant: gm
  - module: services
    id: services
  - module: closing
    id: closing

The full editing and removal workflow is documented in docs/sculpting-guide.md.
