Identity and digital behavior

Name and wordmark

  • Write the full name as “Binyled’s Storyscape” on first reference.
  • Keep the possessive apostrophe and the capital S in Storyscape.
  • Use the display serif for the ceremonial name and the sans serif for descriptors.
  • Do not compress, outline, arch, or add fantasy effects to the wordmark.

Utility seal

  • Use the BS seal only where the full name cannot remain legible, such as a favicon.
  • Keep clear space equal to the width of the B stem on every side.
  • Do not reproduce it below 32 CSS pixels or add a drop shadow.
  • Use only the approved obsidian, verdigris, parchment, and antique-gold combinations.

Interface hierarchy

  • Reserve filled verdigris buttons for consultation or another true primary action.
  • Use underlined text links for exploration and supporting routes.
  • Use hairline rules and spacing before introducing a card or shadow.
  • Keep labels explicit; clarity is a brand behavior, not merely an accessibility requirement.

Identity asset rule

The BS seal is a digital utility mark, not a replacement crest.

The current project does not include the approved dragon-and-shield source artwork. Preserve that recognizable shape when the owner supplies it. Do not fabricate a new dragon, redraw the crest from memory, or let the temporary monogram become the master logo by accident.
