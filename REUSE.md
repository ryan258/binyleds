# Reuse and rights status

General redistribution rights for the project's original code, writing,
identity, and artwork remain pending owner choice. The Storyscape and
Wayfarer Table profiles demonstrate layout reuse in this repository. A
redistributable starter kit needs an explicit licensing decision.

| Material | Current record |
| --- | --- |
| Original code and templates | General redistribution license pending owner choice |
| Original prose and synthetic Lantern Bay / Wayfarer examples | General redistribution license pending owner choice |
| Binyled’s Storyscape identity, glyphs, and collateral | Owner review required for external use |
| Third-party fonts | SIL Open Font License notices in [LICENSES/](LICENSES/) |
| Retained PaperMod-derived material | [MIT notice](LICENSES/PaperMod-MIT.txt) |
| Illustrative scenes | The [asset register](brand/ASSET_REGISTER.md) records the November 2026 scenes and remaining provenance gaps for earlier art |

The [release manifest](data/release.json) records which static files the site
builds require. Check the asset register and rights for any material you plan
to redistribute, including assets that remain in generated output without a
current page placement. Preserve third-party notices in any licensed
distribution. Identify synthetic sessions and generated scenes as examples,
and describe game-system references without implying an affiliation.
